The gap

        
The toy in the box is not the blueprint

        
People review GitHub. Machines install a tarball someone uploaded. Nothing forces those two to be the same.

      


      

        

          
Blueprint

          
The GitHub tree reviewers actually read: source files, tests, a clean package.json.

        

        

          
The box you open

          
The npm tarball that lands in node_modules. It can contain extra scripts, extra files, extra powers.

Why this is hard

        
Two failing ideas, then the one that works

      

      

        

          
Flag every difference

          
Compiled dist/, LICENSE, and metadata always differ. Every package looks dangerous. The tool is useless.

        

        

          
Keep an allowlist

          
Allow dist/ and you miss injected lines. Ban extra files and the next honest project breaks. Allowlists rot.

        

        

          
PkgTruth: compare what code can do

          
Clean builds stay LOW because capabilities are preserved. Tampering is caught when the package gains a power the source never had.
